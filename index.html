I’m a QA Automation Engineer who works across web, mobile, healthcare, government and hospitality platforms. I specialise in Playwright with JavaScript and TypeScript, Page Object Model frameworks, and CI/CD with GitHub Actions and Docker.

I also bring solid REST API validation, SQL testing and Agile delivery, and I use Claude Code and GitHub Copilot to draft tests faster, then verify every result against the running product.
